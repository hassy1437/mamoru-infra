## 1. 案: 点検アプリのプライバシーポリシー（app.mamoruinfra.com/privacy）

★実装はブランチ `claude/nameplate-policy`（mamoru-infra・`src/app/privacy/page.tsx`）。マージは確認のあと。

- **1. 収集する情報** に足す
  > **銘板の写真と読み取りの記録**（「銘板を撮って読む」をお使いになった場合のみ）: 撮影した銘板の写真、AI による読み取りの結果、ご確認のうえ入力された値、使った日時と回数
- **2. 情報の利用目的** に足す
  > 銘板の文字の読み取り（AI による読み取りの結果を表示するため）
  > 銘板の読み取りの精度の評価と改善（どの AI がどの欄を正しく読めたかを集計し、使う AI を選ぶため）
- **3. 情報の第三者提供** に足す（見出し「銘板の読み取りでの外部の AI 事業者への送信」）
  > 「銘板を撮って読む」をお使いになったときに限り、読み取りのため、撮影した銘板の写真を以下の事業者へ送信します。
  > 写真は端末で縮小し、撮影場所などの付帯情報（位置情報など）を取り除いてから送信します。物件名・住所・お名前などは送信しません。
  > 銘板以外のもの（人の顔・書類など）が写らないように撮影してください。
  > - Anthropic, PBC（アメリカ合衆国）: Claude
  > - Google LLC（アメリカ合衆国）: Gemini
  > - OpenAI（アメリカ合衆国）: ChatGPT（API）
  >
  > 各社での写真の取扱い（保存の期間・学習への利用の有無など）は、各社が定める法人向けの API の規約によります。
- **4. データの保管** に足す
  > 銘板の写真は、ご本人と当社の担当者だけが見られる非公開の場所に保管し、撮影から 1 年で削除します（読み取りの結果と入力された値の記録は、精度の評価のために残ります）。
- 最終更新日を直す（マージする日に）

## 5. 下調べ: 3 社の API での写真の扱い（2026-11-04）

★調べ方: 各社の公開の文書を**検索で拾った記載**。この環境からは各社のページを直接開けなかった（privacy.claude.com・ai.google.dev・developers.openai.com は通信の許可が無い）。★各社の文書はよく変わる。ポリシーに書く前に、下の出典を開いて確かめること。

| | Anthropic（Claude） | Google（Gemini・有料） | OpenAI（ChatGPT の API） |
|---|---|---|---|
| 学習に使うか | 使わない（API の既定。利用者が自分で送った意見などは別） | 使わない（有料の口のとき。★無料の枠は製品の改善に使われる） | 使わない（API の既定・2023-03 から） |
| 保存の期間（既定） | 受け取りから 30 日以内に消す | 不正利用の監視のため 55 日 | 不正利用の監視の記録は最長 30 日 |
| 長くなる場合 | 利用ポリシーの違反の疑い（最長 2 年と書いた資料がある）・法令。★「Covered Models」（Fable・Mythos）は 30 日の保存が必須。★使う Haiku は対象外 | 法令・違反の調査 | 法令・害を防ぐため。★例: 2025 年に米国の訴訟で API の記録の保存を命じられた（新しい記録は 2025-09-26 で終わった） |
| 保存ゼロ（ZDR） | 申し込み・審査 | Gemini API では保証されない（Google は Vertex AI を案内） | 申し込み・審査 |
| 別の保存（止められる） | ― | ★**記録（Logs and datasets）**: 2026-10-26 から、有料の新しいプロジェクトは既定で残す → 頼みごとに `store: false` を付けた（点検アプリ #121） | ★**答えの保存（30 日）**: 頼みごとに `store: false` を付けている（前から） |
| 契約の相手 | Anthropic, PBC（欧州・英国の外の客） | Google LLC（Google APIs Terms）。★請求先アカウントは日本だと Google Cloud Japan G.K. を通すことがある（管理画面で確かめる） | OpenAI OpCo, LLC（欧州・スイスの外の客。前の版は OpenAI, L.L.C.） |
| データ処理の取り決め（DPA） | ある | 有料の口は DPA の下で扱う | ある |

★DPA があることは、Q1（委託か・外国の第三者としての措置）の材料になる。どう整理するかは弁護士に。

### ポリシーの書き方の案（★どちらにするかは山本さん・弁護士）
- **案 A（いまの PR）**: 「各社での写真の取扱い（保存の期間・学習への利用の有無など）は、各社が定める法人向けの API の規約によります。」
  - 各社が規約を変えても文を直さずに済む。読む人には中身が分からない
- **案 B（おすすめ）**: 案 A の文の前に「各社とも、送信した写真を AI の学習に使わない条件（法人向けの API）で利用します。各社は不正利用の監視などのため、写真を一定の期間（30〜55 日程度）保存することがあります。」を足す
  - 業者さんが気にする「学習に使われるか」に答えられる。★各社が規約を変えたら直す必要がある（年に 1 回見直す）

### 鍵を作るときの設定（橋本さん・★全員に出す前に）
- **Google**: 請求を有効にした（有料の）プロジェクトで鍵を作る。AI Studio の「Logs and datasets」の設定で Generate Content API の記録をオフにする（コードでも `store: false` を付けている・二重の備え）。★データセットを Google と共有しない。★「Contributor」の割引（データを改善に使わせる代わりに安くなる）を使わない
- **OpenAI**: 組織の設定で、入力と出力を OpenAI と共有する（学習に使わせる）設定をオンにしない
- **Anthropic**: データを共有して割引を受ける仕組みには入らない
- 3 社とも、月の使用額の上限を管理画面で決める
