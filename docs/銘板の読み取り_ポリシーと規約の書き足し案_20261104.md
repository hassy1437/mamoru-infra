## 1. 案: 点検アプリのプライバシーポリシー（app.mamoruinfra.com/privacy）

★実装はブランチ `claude/nameplate-policy`（mamoru-infra・`src/app/privacy/page.tsx`）。マージは確認のあと。

- **1. 収集する情報** に足す
  > **銘板の写真と読み取りの記録**（「銘板を撮って読む」をお使いになった場合のみ）: 撮影した銘板の写真、AI による読み取りの結果、ご確認のうえ入力された値、使った日時と回数
- **2. 情報の利用目的** に足す
  > 銘板の文字の読み取り（AI による読み取りの結果を表示するため）
  > 銘板の読み取りの精度の評価と改善（どの AI がどの欄を正しく読めたかを集計し、使う AI を選ぶため）
- **3. 情報の第三者提供** に足す（見出し「銘板の読み取りでの外部の AI 事業者への送信」）
  > 「銘板を撮って読む」をお使いになったときに限り、読み取りのため、撮影した銘板の写真を以下の事業者へ送信します。
  > 写真は端末で縮小し、撮影場所などの付帯情報（位置情報など）を取り除いてから送信します。物件名・住所・お名前などは送信しません。
  > 銘板以外のもの（人の顔・書類など）が写らないように撮影してください。
  > - Anthropic, PBC（アメリカ合衆国）: Claude
  > - Google LLC（アメリカ合衆国）: Gemini
  > - OpenAI（アメリカ合衆国）: ChatGPT（API）
  >
  > 各社での写真の取扱い（保存の期間・学習への利用の有無など）は、各社が定める法人向けの API の規約によります。
- **4. データの保管** に足す
  > 銘板の写真は、ご本人と当社の担当者だけが見られる非公開の場所に保管し、撮影から 1 年で削除します（読み取りの結果と入力された値の記録は、精度の評価のために残ります）。
- 最終更新日を直す（マージする日に）

## 2. 案: 業務提携規約（登録業者向け・第1編）

★第1編は弁護士の最終確認の前（`lib/terms-part1-content.ts` の頭書き）。★ここは**文案だけ**（コードの差し替え一覧 `PART1_AMENDMENTS` には入れていない。あれは読み合わせで確定したものだけを入れる決まり）。

- **第9条2項の後ろに足す（案）**
  > 報告書作成システムが写真から文字を読み取る機能の結果を用いる場合も同じとし、登録業者は銘板等の原本と照合したうえで入力します。
  - ねらい: AI の読み取りは下書き。消防署へ出す書類なので、最後は業者が確かめる（画面でも「銘板と見比べて」と出している）
- **第20条5項（新設案）**
  > 当社は、登録業者が報告書作成システムの読み取り機能に送信した写真を、読み取りのため、当社が選定する外部の事業者（外国にある事業者を含みます）に送信できます。当社は、当該写真、読み取りの結果及び登録業者が入力した値を、読み取りの精度の評価及び改善のために利用でき、写真は送信から1年を経過した後に削除します。
  - ねらい: 外部（米国）への送信と、精度の評価への利用の根拠。★第20条2項（識別できない統計）だけでは、写真そのものを残して比べる根拠にならない
- **第19条（施設情報）との関係**: 銘板の写真は「施設情報」に当たりうる（設備の製造者・型式）。★利用者（依頼者）との関係で、業者が写真を当社経由で外部に送ってよいかの整理が要る（下の Q4）

## 4. 確認してほしいこと（山本さん・弁護士）

| # | 内容 | 私の考え |
|---|---|---|
| Q1 | 銘板の写真の送信は「委託」か「第三者提供」か。外国（米国）の事業者への送信として、個人情報保護法の「外国にある第三者」の情報（国名・その国の制度・事業者の措置）を書く必要があるか | 写真はふつう個人情報を含まないが、写り込みがありうる。★安全側に、国名は書いた（制度・措置の書き方は弁護士に） |
| Q2 | 各社の API の規約で、送った写真が**学習に使われない**こと・**保存の期間**（不正利用の監視のための保持など）・保持しない設定の有無 | ★私はまだ各社の資料で確かめていない（この環境から開けなかった）。確かめてから「学習に使われません」と書くか決めたい。★Gemini は**有料の API キー**を使う前提（無料の枠は扱いが違うことがある） |
| Q3 | 送り先の正式な会社名（契約の相手）。特に OpenAI は日本から使うときの契約主体の名前 | 案では「OpenAI」とだけ書いた。正式名称に直したい |
| Q4 | 依頼者の建物の銘板を撮って外部に送ることが、第19条（施設情報は個別業務の目的に限り利用）とぶつからないか。依頼者（第2編）側にも何か書くべきか | 報告書を作る業務の一部（目的の内）と読めると考えるが、確認したい |
| Q5 | 画面のボタンの近くに一言「写真は読み取りのため米国の AI 事業者に送ります（詳しくはプライバシーポリシー）」を出すか | ★出すのがおすすめ（使う前に分かる）。決まったら付ける |
| Q6 | サービス名の表記 | 点検アプリの名前が決まったら差し替える（今は「本サービス」） |
