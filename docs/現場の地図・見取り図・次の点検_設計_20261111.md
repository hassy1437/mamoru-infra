## 7. 次の点検まであと○日

- 物件一覧・点検を始める画面のカードのいちばん上と、物件の画面に帯を出す。
- 計算（`src/lib/next-inspection.ts`）:
  - 前回 = その物件の総括表のうち、点検日が今日（日本時間）までで いちばん新しいもの
  - 次の機器点検 = 前回（種類を問わない）＋6 か月。次の総合点検 = 前回の総合点検＋1 年。早いほう（同じ日なら総合）
  - 点検日が今日より後の総括表があれば「予定」
- 帯の色: 過ぎた＝赤／30 日以内＝黄／それより先＝灰／予定＝青／記録なし＝薄い灰。
- 並び: 「点検が近い順」（最初）と「登録が新しい順」をタップで切り替え。
- DB の変更は無い。

## 3. 現場の位置（地図にピン）

- 物件の画面に「現場の位置」:
  - 位置が無い → 「いまここにする」（端末の位置をそのまま保存。取り消せる）／「地図で選ぶ」
  - 位置がある → 小さい地図＋「ナビ」（Google マップの経路・キー無し）／「位置を直す」
- 地図は国土地理院の標準地図（Leaflet）。ピンは真ん中に固定し、地図を動かして合わせる（手袋でも合わせやすい）。出典「国土地理院」を出す。
- 「地図で選ぶ」「住所の場所」を押したときだけ、物件の住所を国土地理院の住所検索に送る。
- 物件一覧・物件の画面の地図リンクも、位置があれば「ナビ」になる。
- DB: `inspection.properties.location_lat / location_lng`（マッチングサイトのリポジトリの `20261231160000`）。日本の範囲だけ・どちらも空か、どちらも値。見てよい人は今の物件と同じ（会社の人なら）。

## 6. 見取り図に設備の印

- 物件の画面の「見取り図」から開く（点検票の一覧からも開ける）。
- 階を選ぶ（地下〜地上〜R・物件の階数から）→「撮る」（避難経路図など）→ 下の設備を選ぶ → 図をタップで印。印をタップ →「消す」。
- 設備のボタンは物件の設備に合うものを先に（＋その他・ほか）。押したボタンは選ばれたままで、続けて置ける。種類ごとの数を出す。
- 全体・2 倍・3 倍。撮り直しは、新しい写真を置いてから古いものと印を消す（電波が切れても前のが残る）。
- 写真は端末で 2000px の JPEG に縮めてから、非公開の置き場 `floor-plans` の `<会社 ID>/<物件 ID>/…` に置く。会社の人だけ読める・消せる。上書きはできない。
- 物件を消すときは、先に写真を置き場から消す（表の行は物件から自動で消えるが、置き場のファイルは SQL から消せない）。
- DB: `inspection.floor_plans`（物件の階ごとに 1 枚）・`inspection.floor_plan_pins`（設備の種類と図の中の位置 0〜1）。マッチングサイトのリポジトリの `20261231170000`。会社の人なら読み書きできる。ほかの会社の物件・見取り図には足せない。写真の名前は自分の会社と物件のフォルダだけ。
- 設備の種類（12 種）は `src/lib/floor-plan-kinds.ts` と DB の決まりの両方にある（足すときは両方直す）。

## 決めたこと（2026年11月11日・橋本さん「おすすめで」）

1. プライバシーポリシー（点検アプリ）に足した: 物件の位置と見取り図（1. 収集する情報）、端末に覚える印（5. ローカルデータ）、6. 地図と位置（国土地理院の地図と住所検索・いまここ・Google マップ）。★マージは山本さんの確認のあと。最終更新日は公開する日に合わせる
   - ★気づいたこと: 4. データの保管の「ユーザーごとにデータが分離され」は、会社単位にした（20261231120000・本番適用済み）あとの実態と合っていない（同じ会社の人は見られる）。今回は触っていない（山本さんの確認のときに一緒に見てもらう）
2. 前回の点検をボタンで: 総括表がまだ無い物件は、物件の画面の「前回の点検を選ぶ」→ 機器点検／総合点検 → 月（今月から 12 か月・「もっと前」で 24 か月）。帯は「○月ごろ」。物件一覧の「記録なし」から、物件の画面のその場所へ飛ぶ。総括表のほうが新しければそちらを使う。DB は `inspection.properties.last_inspection_month`（月の 1 日）/ `last_inspection_kind`（`20261231160000` に足した）
3. 電波の無い所の印: 端末（localStorage）に覚えて、電波が戻ったら・画面を開いたら・「いま送る」で送る（`src/lib/floor-plan-queue.ts`）。送っていない印は点線の輪、上に「まだ送っていない印 ○ 個」。★写真は覚えない（撮るのは電波のある所で）。★送れない理由が電波でない（見取り図が撮り直された・消された）ときは捨てて知らせる。印を消す・不良の付け外しは、送っていない印なら端末の中だけで
4. 不良の目印: 印をタップ →「不良」で付け外し。赤い太い輪と「!」。DB は `inspection.floor_plan_pins.defect`（`20261231170000` に足した）
